# PlantillaPro Studio v1.0.0

Primera versión pública estable de PlantillaPro Studio.

## Funciones principales

- Creación de plantillas personalizadas desde imágenes PNG, JPG y JPEG.
- Campos variables como `{{nombre}}`, `{{numero}}`, `{{curso}}` y otros datos importados.
- Numeración automática configurable con inicio, cantidad, incremento, ceros a la izquierda, prefijo y sufijo.
- Generación de talonarios sin necesidad de cargar un Excel o CSV.
- Cálculo automático de cuántas piezas entran en una hoja según su tamaño físico, márgenes y separaciones.
- Relleno completo en vertical y horizontal, o únicamente vertical.
- Modo **Apilado para cortar**, que mantiene la secuencia al imprimir, apilar las hojas y cortar cada posición.
- Previsualización por hojas completas.
- Exportación a PDF e imágenes individuales.
- Guardado y apertura de proyectos JSON.

## Descarga para Windows

Descarga `PlantillaProStudio-v1.0.0-windows-x64.zip`, descomprímelo y ejecuta:

`PlantillaProStudio.exe`

No es necesario instalar Python.

## Verificación

El archivo `SHA256SUMS.txt` contiene la suma SHA-256 del paquete descargable.

## Nota de Windows

La aplicación todavía no está firmada digitalmente. Windows SmartScreen puede mostrar una advertencia la primera vez que se ejecute; revisa que el archivo provenga de este repositorio y utiliza la suma SHA-256 para verificarlo.
